# Debug & Grow author: Andrés Felipe Lozada Manzano program: Análisis y Desarrollo de Software — SENA ficha: 3388935 evidence: GA5-240202501-AA2-EV03 ## What is this? A developer's journal about building English skills the same way you debug code — methodically, honestly, and without pretending the errors don't exist. Every post in this blog connects a real piece of English evidence (a cover letter, a mind map, a spoken recording) to the mindset of a software apprentice: ship, observe, iterate, improve. ## Why "Debug & Grow"? Because bugs are not shameful. They are information. The same is true for language errors. ✓ status: actively maintained
